# Contributing

Thanks for your interest in contributing to Butik.

Butik is an open-source reference implementation for multi-tenant commerce, store-scoped APIs, storefront customization, and ecommerce dashboard architecture.

Useful contributions include:

- Bug fixes
- Documentation improvements
- Test coverage
- UI/accessibility improvements
- Security reviews
- Ecommerce workflow improvements

Before opening a large pull request, please open an issue describing the change.

Please do not commit secrets, API keys, database URLs, or production credentials.
